# no-string-app-

A speakeasy-themed web application with password protection and interactive elements.

## Features

- **Speakeasy Theme**: 1920s prohibition era styling and atmosphere  
- **Password Protection**: Secret entrance with multiple accepted passwords
- **Interactive Elements**: Animated UI, Easter eggs, and special effects
- **Automated Testing**: Puppeteer-based end-to-end testing

## Quick Start

```bash
# Install dependencies
npm install

# Start the server
npm start

# Run automated tests (requires server to be running)
npm run puppeteer
```

## Testing

The application includes comprehensive Puppeteer automation that tests all user flows including password validation, navigation, and interactive features. See [PUPPETEER.md](PUPPETEER.md) for detailed testing documentation.
